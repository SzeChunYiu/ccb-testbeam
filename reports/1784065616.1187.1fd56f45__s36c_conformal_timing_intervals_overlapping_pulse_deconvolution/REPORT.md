# S36c: Conformal Timing Intervals for Overlapping-Pulse Deconvolution

## Abstract

Ticket `1784065616.1187.1fd56f45` asks whether conformal calibration fixes the S36b
overlapping-pulse timing-interval under-coverage without sacrificing overlap
average precision (AP), timing accuracy, energy bias, or PID-proxy stability.
The worker is `testbeam-laptop-3`.  The winner written to `result.json` is
**`ridge:split_conformal`** at 95% nominal coverage.  Its
synthetic-injection coverage is `0.926` with run-block
bootstrap CI [`0.9058`, `0.9511`],
mean interval width `26.79` ns, timing RMSE
`7.391` ns, overlap AP `0.8093`, and
energy bias `0.002529`.

Synthetic overlaps are generated by injecting two shifted stave templates plus

`w(t)=A_1T_s(t-t_1)+rA_1T_s(t-t_1-Delta)+epsilon_rs(t)+p`,

and applying `w_obs(t)=min(w(t), 11800)`.  The real high-rate stratum is
a raw-waveform proxy: held-out rows from runs 64/65, high-pedestal states, or
nonzero clipping fraction.  It is not treated as external truth; it tests width,
AP, energy-bias, and PID-proxy stability under high-rate-like raw conditions.

The S36b uncertainty target is represented by the `tiny_sequence_transformer`

interval is intentionally evaluated as a frozen S36b-style uncertainty proxy;
the conformal policies alter only interval widths and centers, not the point
predictions.

## Conformal Methods and Equations

For each method, define the timing residual

`r_i = 10 ns (hat t_1i - t_1i)`.

The native S36b proxy interval uses a residual-scale half width `h_native`.
Split conformal uses the train calibration set

`h_split(q)=Quantile_{ceil((n+1)q)/n}(|r_i - median(r)|)`,
where `q` is the nominal coverage.

Run-block conformal first computes this quantile inside each calibration run and
then takes the same conformal quantile across run-level widths:

`h_block(alpha)=Q_run({Q_i(|r_ri - median_r r_ri|)})`.

Intervals are `I_i=[hat t_1i - h, hat t_1i + h]`.  We report 68% and 95%
coverage, width, overlap AP, timing RMSE, energy bias, and PID-proxy confusion
span.  CIs are 95% percentile intervals from `400`
held-out run-block bootstrap resamples.

The ranking score for the 95% synthetic-injection endpoint is

`C = |coverage-0.95| + 0.010 width + 0.010 RMSE_t + 0.20|bias_E| + 0.08(1-AP) + 0.05 PID_span`.

## Systematics and Caveats

The coverage claims are exact only for the controlled synthetic-injection target:
truth is known because two-pulse overlaps are injected into raw-ROOT-derived
clean pulses.  The real high-rate stratum is a raw-data stress proxy and cannot
prove truth coverage without external timing labels.  The ADC clip is a benchmark
operator rather than decoded electronics metadata.  PID effects are represented
by stave and charge-support proxy classes, so `pid_proxy_confusion_span` is a
stability diagnostic, not particle-identification truth.  Run-block bootstrap
CIs quantify transfer across five held-out runs and do not turn correlated
events inside a run into independent experiments.

## Verdict

The native S36b TCN proxy under-covers at 95% coverage (`0.8`).
Split conformal and run-block conformal intervals restore coverage by widening
the timing interval while leaving AP, point timing RMSE, and energy bias fixed
for the underlying point estimator.  The selected winner is
`ridge:split_conformal` because it is closest to nominal
coverage with the lowest width-adjusted deployment cost.

Runtime was `228.9` s on `Linux-5.15.0-139-generic-x86_64-with-debian-bullseye-sid`.
