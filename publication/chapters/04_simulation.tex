\section{Simulation programmes}

\subsection{CCB event simulation}

The CCB event simulation provides particle identities, trajectories and energy deposits across the two-arm detector. Historical production used Geant4 electromagnetic and hadronic/ion transport suitable as a starting point for proton/deuteron studies in this energy domain~\cite{Agostinelli2003,Allison2016}. The simulation is used for truth-level stopping and for testing how detector segmentation changes observables.

The elastic p--d angular source table used by the current source-model work is bound to the 190-MeV centre-of-mass differential cross sections reported in Table VI of Ermisch et al.~\cite{Ermisch2005}. A deterministic inverse-CDF implementation defect in the source sampler has been repaired: the current source explicitly defines its interpolation and measured-support policy and can generate the nominal central-value law with unit event weights for direct-sampled campaigns. This bounded source-sampler closure must not be confused with publication-MC closure. The source-model uncertainty is now quantified at source level: a $\pm3\%$ per-node envelope mapped to the point-to-point systematic stated by the measurement, closed against $5{,}000{,}000$ common-random-number draws with the row-statistical (diagonal) replica propagation validated against the delta-method reference, and propagated to lab-frame angles by exact two-body kinematics (mean $\theta_\mathrm{lab}=39.35^\circ$, envelope band $38.81$--$39.89^\circ$). Production campaigns nevertheless generate central values only; campaign-level and detector-response propagation, surviving support/model alternatives, exact production provenance and downstream detector-response dependencies remain separate requirements.

Legacy samples can contain non-unit primary-event weights from a generator source-measure implementation whose frame/Jacobian semantics were later found to be defective. The legacy one-million-event paper MC file is byte-hashed but is not yet bound to a complete production receipt containing generator revision, cross-section table/mode, seed, physics list, build/toolchain and all geometry/material configuration. That legacy file therefore remains a historical provenance-gated diagnostic rather than the nominal publication MC. A regenerated 100{,}000-event campaign now carries a complete production receipt (generator source-pair and cross-section-table digests with the direct-CDF sampling mode, executable and runtime-stack identity, serial single-worker configuration) in a machine-readable manifest; engine seeding is recorded honestly as default per-run seeding.

\subsection{Single-stave optical simulation}

The single-stave model transports the charged particle through a detailed scintillator/fibre geometry and follows optical photons through scintillation, wavelength shifting, attenuation and sensor boundaries. A separate SiPM/electronics layer converts sensor arrivals into avalanche/charge/waveform quantities.

The model is scientifically most useful when represented as a causal graph:
\[
E_{\rm raw}\rightarrow E_{\rm vis}\rightarrow N_{\gamma,\rm scint}
\rightarrow N_{\gamma,\rm WLS\,abs}\rightarrow N_{\gamma,\rm WLS\,emit}
\rightarrow N_{\gamma,\rm sensor}\rightarrow N_{\rm primary\,aval}
\rightarrow Q\rightarrow A_{\rm ADC}.
\]
Here \(E_{\rm raw}\) is unquenched deposited energy and \(E_{\rm vis}\) is the Birks-visible energy. These two variables must never share the same bare \(E_{\rm dep}\) label.

The current single-stave source explicitly separates the fibre inner and outer cladding materials and records the WLS secondary-multiplicity parameter in the optical configuration. These implementation repairs post-date the July optical calibration grid used by the historical response studies. Therefore the old grid is a superseded model diagnostic; it has been regenerated from the current source (2026-08) with explicit $E_{\rm raw}$ and $E_{\rm vis}$ semantics, and promotion of absolute optical-response or energy-reconstruction numbers remains gated on propagating the optical/SiPM nuisance envelope and on broader held-out coverage.

\subsection{Simulation evidence classes}

Paper figures distinguish truth-level Monte Carlo, digitised Monte Carlo, model-dependent optical Monte Carlo, and calibrated-detector evidence. The last category is intentionally empty until response nuisances and held-out data closure satisfy the publication gate.
