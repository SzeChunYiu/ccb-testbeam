## Atom contract

Input is one exact MC ROOT byte stream, tree `hibeam`, with per-generator-entry jagged `Sci_bar_{LayerID,LayerID1,PDG,EDep,Time}` and `PrimaryWeight`. The output is one row per Sample-II generator event, not one row per transport hit or track. Each row carries stable content-bound event ID, global entry index, Sample-I and Sample-II membership, exactly one event weight, and eight B-stave deposited-energy totals plus charged-only diagnostics.

Units: `Sci_bar_EDep` and event/stave totals are MeV; trigger times used by the existing trigger contract are ns; weights are dimensionless. Statistical unit is `generator_event`. This product is explicitly `NONAUTHORISING_TRUTH_DIAGNOSTIC`.

For event `e` and B stave `k`,

`E_dep(e,k) = sum_h EDep_h I(event_h=e, arm_h=B, layer_h=k)`.

The charged-only diagnostic is

`E_dep_ch(e,k) = sum_h EDep_h I(event_h=e, arm_h=B, layer_h=k, q_h!=0)`.

The measure used by downstream weighted summaries is therefore

`mu = sum_e w_e delta_{E_dep(e,k)}`,

with one generator weight per event row. Kish ESS is `(sum_e w_e)^2 / sum_e w_e^2`.

## Competing microscopic/software mechanisms

1. **Legacy hit-record world:** each charged `Sci_bar_EDep` record is a statistical observation and the event weight is repeated per record. Rejected as the DATA event-pulse analogue and non-invariant to transport-step representation.
2. **Track/stave world:** sum steps per truth track/stave. Survives as H2 mechanism diagnostic, but multiple tracks in one DAQ/generator event still do not match a reconstructed event/stave pulse.
3. **Charged-only event/stave world:** sum only charged-record EDep per event/stave. Retained as a diagnostic, not selected as total detector energy because neutral secondaries can deposit energy in a scintillator event.
4. **All-particle event/stave EDep world:** sum every `Sci_bar_EDep` record in the B stave inside one generator event. Selected H3 intermediate.
5. **Quenched/visible event/stave world:** survives as H4 child requiring stepwise quenching/material response.
6. **Digitized/reconstructed event/stave world:** survives as H5 and is the only candidate DATA-pulse analogue after optical/WLS, SiPM, electronics, sampling and identical reconstruction.

Equivalent row-splitting descriptions are collapsed: if one transport record of energy `E` is replaced by records `E_j` with `sum_j E_j=E`, H3 must be identical even though the H1 record count/distribution changes.

## Eliminations and invariants

Transport-step splitting falsifies the claim that raw hit rows are an invariant statistical unit. Multi-record/multi-track deposits are deliberately collapsed to one event/stave row. Sample I is stored as a membership bit inside the Sample-II row universe rather than duplicating the event, preserving `Sample I subset Sample II`. A-arm deposits are excluded from B-stave energy. Missing/nonfinite/negative first-primary weights fail closed in weighted mode instead of silently becoming 1.0; `--no-weight` is an explicit diagnostic mode.

The legacy `EDEP_CAP=600000` prefix-retention mechanism is not present in the new product. No event-order cap is permitted in the H3 arrays. `--max-events` is explicit and manifest-labelled `PREFIX_DIAGNOSTIC`; zero means full tree.

Source provenance uses one opened regular file. SHA-256/byte count are measured from that descriptor, Uproot consumes a duplicate seekable stream from the same open file description, and `(dev,ino,nlink,size,mtime_ns,ctime_ns)` must remain stable through consumer exit. Event IDs reuse the existing `sha256(file bytes) + tree + entry index` contract.

## Executed falsifiers

New tests on PR #1169 cover:

- exact transport-step splitting invariance of total and charged event/stave EDep while record count changes;
- multi-record same-stave aggregation;
- a proton + neutron fixture where all-particle B0 EDep is 5 MeV but charged-only EDep is 2 MeV;
- A-arm exclusion;
- negative/nonfinite EDep, fractional/out-of-range B layer and jagged-length mismatch rejection;
- missing/nonfinite/negative PrimaryWeight rejection and explicit no-weight positive control;
- duplicate event ID, broken Sample-I subset relation, out-of-Sample-II row and charged>total corruption rejection;
- exact opened-source digest/bytes and in-place mutation rejection during the consumer lifetime;
- a mocked Uproot integration proving a file-like stream is passed, a three-event source becomes two Sample-II rows with one Sample-I row, weights remain `[2.0,0.5]`, all-particle/charged B0 totals remain distinct, and event IDs are unique.

A private isolated aggregation harness, using minimal import stubs and excluding the builder-integration test, returned 16 passed. This is not repository validation; only exact-head GitHub CI can authorize merge. No real ROOT or Geant4 production sample was available in this runtime.

## Four sequential review passes

### A. Detector / Geant4 response lead
Background: scintillator energy-deposition scoring, Geant4 transport, detector response chains.
Evidence: legacy charged-hit accumulator/NPZ producer, existing event builder/trigger contract, new aggregation equations and neutral-deposit fixture.
Strongest counter-hypothesis: charged records alone are sufficient because trigger formation is charged-particle based.
Attempted falsifier: proton 2 MeV + neutron 3 MeV in the same B0 event. Trigger charge and detector deposited-energy scope are different contracts; all-particle total is 5 MeV while charged diagnostic is 2 MeV.
Residual uncertainty: whether `Sci_bar_EDep` scoring itself is complete/correct, and all H4/H5 response physics.
Vote: **ACCEPT H3 all-particle event/stave intermediate / BLOCK detector closure**.

### B. Adversarial mechanism / software reviewer
Background: provenance, aggregation invariance, failure injection, event identity.
Evidence: `EDEP_CAP`, hit-row serialization, stable-event-ID code, same-open-file source guard, hostile tests.
Strongest counter-hypothesis: repeated hit rows are harmless if every row receives the same event weight.
Attempted falsifier: split one 4 MeV record into 1.5+2.5 MeV records. H3 remains exactly 4 MeV; H1 record multiplicity changes, so iid hit-row inference is representation dependent.
Residual uncertainty: full production ROOT scale/memory and the pre-existing 16-hex event-ID truncation, although this product validates uniqueness within each generated artifact and binds the full source SHA in metadata.
Vote: **ACCEPT bounded product contract / REVISE production-scale execution**.

### C. Independent statistics / validation reviewer
Background: weighted empirical measures, clustered data, effective sample size, trigger-topology resampling.
Evidence: #1164/#1166 null falsifiers and one-weight-per-event product design.
Strongest counter-hypothesis: repeated weights on transport rows reproduce the same weighted distribution after normalization.
Attempted falsifier: representation splitting changes the empirical row measure while event aggregation is invariant; storing Sample-I membership rather than a second physical row also preserves the joint sample graph required by #1166.
Residual uncertainty: nonuniform real PrimaryWeight distribution, dominant weights/low ESS, event clustering beyond one generator entry, ties/saturation and nuisance calibration.
Vote: **ACCEPT statistical-unit/topology contract / BLOCK authorising p-value**.

### D. Claims / provenance reviewer
Background: claim ledger, source-to-result traceability, publication-state gating.
Evidence: metadata state, source SHA/descriptor identity, declared missing detector stages, #1052/#1049 blockers.
Strongest counter-hypothesis: event-level EDep plus one fitted MeV->ADC scale is sufficient for DATA/MC detector comparison.
Attempted falsifier: the product contains no quenching, optical/WLS, SiPM, electronics, digitizer or DATA-like reconstruction state; a scalar gain cannot establish those transformations.
Residual uncertainty: exact production artifact is not regenerated; downstream consumer is not yet migrated.
Vote: **BLOCK claim promotion; ACCEPT nonauthorising provenance contract**.
