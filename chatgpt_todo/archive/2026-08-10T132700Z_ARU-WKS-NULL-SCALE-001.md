## 1. Exact atom contract

Current `scripts/compare_data_mc.py` estimates

`shat = median(DATA_II) / weighted_median(MC_II, PrimaryWeight)`

and uses the same scalar in

`T_II = D(DATA_II, shat * MC_II)`

and

`T_I = D(DATA_I, shat * MC_I)`.

The nuisance is therefore part of the statistic-generating map, not external metadata. An authorising null replicate must reproduce the estimator and the fit/test population graph.

Units at the current legacy boundary are ADC / MeV-hit-record. That dimensional ratio is mathematically defined but physically non-authorising because #1052 establishes that the MC operand is hit-record EDep rather than detector-event B2 response, and #994 establishes that multiple ADC/MeV quantities with different truth types already coexist.

## 2. Repository population graph

Evidence inspected:

- `configs/s00_reproduction.yaml`: Sample-I analysis DATA runs = 44–57; Sample-II analysis DATA runs = 58,59,60,61,62,63,65. These run families are disjoint.
- `scripts/mc01_trigger_split_truth.py`: Sample II = ENTER B; Sample I = ENTER A and ENTER B within the coincidence window. The producer appends an event to II when `enterB`, and additionally to I when `coinc`, so MC-I is a subset of MC-II.
- `scripts/compare_data_mc.py`: the Sample-II median ratio is reused for Sample-I and Sample-II discrepancies.

Thus the calibration topology is asymmetric:

`DATA_I ∩ DATA_II = empty` at canonical run-family level,

while

`MC_I subset MC_II` by trigger construction.

This is a covariance contract that cannot be recovered from marginal NPZ arrays after source-event/sample-membership identity is discarded (#1164).

## 3. Mechanism universe and equivalence collapse

### H1 — frozen fitted scale

Estimate `shat` once and hold it fixed in every null replicate. For same-sample Sample-II GOF this does not reproduce the map used to obtain the observed statistic. Rejected by the equal-weight composite-null falsifier below.

### H2 — refit inside every replicate

Regenerate/resample the declared calibration populations and recompute `shat*` before evaluating the replicate discrepancy. Survives the local nuisance falsifier. It is not yet a validated CCB method because weights, event clusters, ties, detector response and sample topology remain unresolved.

### H3 — external/held-out nuisance

Use a source-disjoint calibration population and condition on its fitted scale. Survives in principle, but requires explicit held-out provenance and transfer validation. It is observationally distinct from H2 because the nuisance uncertainty/covariance enters differently.

### H4 — topology-blind Sample-I resampling

Regenerate MC-I independently of MC-II despite the actual trigger hierarchy. Rejected: it destroys covariance between the Sample-II scale denominator and Sample-I MC observable.

### H5 — topology-preserving Sample-I resampling

Preserve common generator-event identities and the subset membership graph inside every replicate. Required survivor if the current trigger hierarchy remains canonical.

### H6 — no inferential p-value

Retain the corrected weighted ECDF `D` as descriptive only. This remains the authorising public state until H2/H3 plus H5 and all cross-scale dependencies are validated.

Procedures that differ only by ordering of a frozen scalar collapse into H1. Procedures that independently redraw fit/test marginals but do not preserve membership collapse into H4.

## 4. Equations / invariants / identifiability

Let `g` be the calibration estimator and `T` the weighted EDF discrepancy.

`shat = g(D_II, M_II, w_II)`

`T_II = T(D_II, shat M_II, w_II)`

`T_I = T(D_I, shat M_I, w_I)`.

A null replicate `b` must either evaluate

`shat_b = g(D_II,b, M_II,b, w_II,b)`

before `T_b`, or establish that `shat` came from an external population independent by design. For Sample I, the replicate must preserve the source membership relation `M_I,b subset M_II,b` unless a different held-out design is explicitly adopted.

A topology-blind procedure is not identifiable from marginal amplitude/EDep arrays: two joint designs can have the same `P(M_I)` and `P(M_II)` but different covariance through shared event identity and therefore different distributions for `(shat,T_I)`.

## 5. Executed synthetic falsifier A — nuisance refit

Environment used for the independent in-session computation:

- Python `3.13.5`
- NumPy `2.3.5`
- Linux `6.18.35-x86_64`, glibc `2.41`
- deterministic seed base `20260810`

Design:

- DATA = `90 * LogNormal(0,0.5)`;
- MC = `LogNormal(0,0.5)`;
- `n_DATA=80`, `n_MC=160`;
- **unit weights** to isolate nuisance fitting from PrimaryWeight;
- 200 outer null trials;
- 99 parametric-bootstrap replicates/trial;
- observed `D` uses median-ratio `shat`;
- fixed world keeps outer `shat` in the bootstrap statistic;
- refit world recomputes the median-ratio in every bootstrap replicate.

Results:

- alpha 0.05 rejection: fixed `0.000`; refit `0.060`;
- alpha 0.10 rejection: fixed `0.015`; refit `0.095`;
- mean p: fixed `0.67775`; refit `0.5378`;
- mean observed `D`: `0.0963125`;
- mean fixed-null `D`: `0.1148734217`;
- mean refit-null `D`: `0.0974835859`.

The fixed procedure is strongly conservative in this declared fixture. This is a method falsifier, not evidence that the refit procedure is calibrated for CCB.

## 6. Executed synthetic falsifier B — overlap topology

Environment as above; seed `20260811`.

Design:

- 2,000 trials;
- MC-II = 160 LogNormal events;
- MC-I = Bernoulli-0.4 subset of MC-II (mean size 64.109);
- DATA-II and DATA-I independently generated under the same scale family;
- `shat` fitted from Sample II;
- compare topology-preserving MC-I against a replacement MC-I independently drawn from the same marginal distribution.

Results:

- corr(`shat`, median(MC-I)) preserved = `-0.4358878983`;
- corr after breaking subset membership = `0.0033154082`;
- mean Sample-I `D`: preserved `0.1492650532`, broken `0.1584225795`;
- 95th percentile `D`: preserved `0.2408004779`, broken `0.2575757576`.

Therefore identical one-sample marginals do not determine the Sample-I null law; the joint membership graph is material.

## 7. Primary literature / authoritative method context

- Capasso, Alessi, Barigozzi & Fagiolo, *Advances in Complex Systems* 12 (2009) 157–167, DOI `10.1142/S0219525909002131`: EDF GOF with unknown parameters; supports the general need to represent parameter estimation in Monte-Carlo calibration and documents over-conservative behavior when parameters are not re-estimated.
- Kojadinovic & Yan, *Canadian Journal of Statistics* 40 (2012) 480–500, DOI `10.1002/cjs.11135`: treats GOF empirical processes with estimated parameters as a distinct bootstrap problem.

Source-to-claim boundary: neither paper validates the CCB importance-weighted clustered two-sample design or its detector chain. They support only the generic nuisance-estimation principle.
