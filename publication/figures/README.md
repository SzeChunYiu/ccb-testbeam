# Publication figures

Figures are separated by **scientific authorisation state**.

- `final/`: only figures whose claim status permits publication. Currently intentionally sparse/empty while the central reruns are open.
- `gated/`: source-backed plots retained for provenance but forbidden as final paper evidence.
- `model_diagnostics/`: simulation or method-closure plots that may be cited only with their explicit evidence class.
- `illustrative/`: schematics with no measured headline number.
- `source_data/`: index/links to the machine-readable tables/results used to render figures.

Do not promote a file by copying it between folders. Promotion requires the canonical claim/status gate and a regenerated source bundle.
