**PIDA-01 CONFIRMED: AP omits first positive-recall increment.** In scripts/studies/clusterA_dE_PID_stopping.py, roc_pr sets rec=tp/P but computes sum((rec[1:]-rec[:-1])*prec[1:]), omitting the initial increment from zero to rec[0]. In a perfectly ranked one-positive/one-negative fixture, legacy AP=0 while standard noninterpolated AP=1. Untied scores suffice. Actual reported AP 0.7503359264707785 cannot be corrected without source OOF scores; for 330 equal-weight positives the omitted first contribution is at most 1/330, in addition to any ties effect.

**PIDA-02 CONFIRMED: ROC/AP fail to group tied scores.** Legacy ROC integrates a point after *every record* even when scores are equal. Two tied observations with opposite classes yield legacy AUC 1 or 0 depending only on row order, while correct AUC=0.5. Its AP also changes. Exact tied-score prevalence in production OOF scores is NOT_EVALUATED. Current score_logit clips logits to [-35,35], making ties possible but not proving their occurrence.

**PIDA-03 CONFIRMED on reported population: bootstrap never samples 423 events.** boot_tpr uses nb=max(1,ne//500). Source counts have 5,093 proton + 330 deuteron = 5,423 scored events. Only 5,000 can appear in any bootstrap replicate: 423/5423=7.80011064% are completely excluded. Synthetic stress: if all positives occur in last 423, full AUC exists but legacy bootstrap returns no ROC confidence band. Actual uncertainty impact NOT_EVALUATED. Consecutive pseudo-500-event blocks are not verified independent generator runs.

**PIDA-04 CONFIRMED: reported 5 folds contain only 3 nonempty test groups.** folds=(arange(5423)//2000)%5 yields [2000,2000,1423,0,0], not five independently evaluated physical runs. counts.json stores three AUC values and two literal NaNs; source nanmean averages only three. Current counts.json's bare NaN tokens are also not valid strict JSON.

**PIDA-05 SCOPED INTERPRETATION:** classifier features include log(ekin_entry) of the energy-dominant MC truth track. That true track energy is not established as a beam-detector-observable measurement; this is truth-conditioned MC PID unless a detector-only feature ablation and calibration exist. Labels are dominant depositing-track species, not necessarily incident species. PR1554's reported 0.952905 AUC and 0.750336 AP were NOT recomputed from original scores. The 0.898->0.953 difference compares changed MC/selection populations, not a controlled detector-performance improvement.
